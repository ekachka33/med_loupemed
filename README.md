# Проект "сайт медицинской диагностики"

## Описание проекта

"Med Loupemed" — это веб-приложение для медицинской диагностической клиники, разработанное на фреймворке Django. Цель проекта — предоставить удобную платформу для пациентов и инструмент управления для персонала клиники.

**Ключевой функционал:**
* **Управление контентом сайта:** Легкое обновление информации "О компании", контактных данных и раздела "Вопросы и ответы" (FAQ) через административную панель.
* **Каталог услуг:** Детальное описание медицинских услуг с возможностью группировки по категориям и подробными прайс-листами.
* **Профили врачей:** Информация о специалистах клиники, их биографии, опыте и расписании.
* **Онлайн-запись на прием:** Удобная система для пациентов, позволяющая записываться на прием к конкретному врачу на выбранную услугу в доступные временные слоты.
* **Личный кабинет пациента:** Регистрация, авторизация, просмотр истории записей и доступ к медицинским записям/результатам диагностики (загружаемым врачами).
* **Формы обратной связи:** Возможность оставить заявку на звонок или задать вопрос.
* **Отзывы:** Система сбора и модерации отзывов клиентов о клинике и врачах.
* **Административная панель:** Инструмент для управления данными проекта: пользователями, врачами, услугами, записями, запросами обратной связи, отзывами, медицинскими записями и общим контентом сайта.

## Используемые технологии

* **Backend**: Python 3.10+, Django 4.2+
* **Database**: PostgreSQL 13+
* **Web Server (Production)**: Gunicorn
* **Static Files Serving**: Whitenoise
* **REST API**: Django REST Framework (для получения временных слотов для записи)
* **Containerization**: Docker, Docker Compose
* **Frontend**: HTML, CSS, JavaScript, Bootstrap (для адаптивного и современного интерфейса)
* **Изображения**: Pillow
* **Переменные окружения**: python-dotenv
* **Формы**: Django-Crispy-Forms (с crispy-bootstrap5)
* **Тестирование**: Coverage.py
* **Стандарты кода**: PEP8

## Модели данных (`core/models.py`)

Проект использует следующие ключевые модели для организации данных:

* **`ContactRequest`**: Запросы обратной связи и "обратный звонок" от пользователей.
* **`AboutUsPage`**: Контент для страницы "О компании" (история, миссия, ценности).
* **`ContactInfo`**: Контактная информация клиники (адрес, телефоны, email, ссылки на соцсети).
* **`Doctor`**: Информация о врачах, их специализации, биографии, опыте и привязка к пользовательскому аккаунту.
* **`Review`**: Отзывы клиентов о клинике или конкретных врачах.
* **`ServiceCategory`**: Категории медицинских услуг.
* **`Service`**: Основные медицинские услуги с описанием, ценой, длительностью и привязкой к врачам.
* **`ServicePriceItem`**: Детальные пункты прайс-листа для услуг, если цена варьируется.
* **`Appointment`**: Записи пациентов на прием, включая статус, комментарии и результаты диагностики.
* **`DoctorSchedule`**: Расписание работы врачей по дням.
* **`MedicalRecord`**: Загружаемые файлы медицинских записей и результатов анализов, привязанные к приему.
* **`FAQItem`**: Вопросы и ответы для раздела FAQ.

## Установка и Запуск Проекта

Эти инструкции помогут вам настроить и запустить проект на вашей локальной машине с использованием Docker.

### Требования

* [Docker Desktop](https://www.docker.com/products/docker-desktop) (или Docker Engine и Docker Compose)
* Git (для клонирования репозитория)

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL_вашего_репозитория>
    cd med_loupemed
    ```
    *(Замените `<URL_вашего_репозитория>` на фактический URL вашего Git-репозитория)*

2.  **Создайте файл переменных окружения `.env`:**
    Создайте файл `.env` в корневой директории проекта (там же, где находится `docker-compose.yml`). Этот файл содержит важные настройки и чувствительные данные.
    Пример содержимого `.env`:
    ```env
    # Настройки Django
    SECRET_KEY='ваш_очень_секретный_ключ_здесь' # Обязательно сгенерируйте уникальный и сложный ключ!
    DEBUG=True # Для разработки. В продакшене установите False
    ALLOWED_HOSTS='localhost,127.0.0.1' # Разделяйте запятыми без пробелов. В продакшене - доменное имя.

    # Настройки базы данных PostgreSQL
    DB_NAME=med_loupemed_db
    DB_USER=meduser
    DB_PASSWORD=medpassword
    DB_HOST=db
    DB_PORT=5432

    # Настройки электронной почты (пример, если используется отправка писем)
    EMAIL_HOST=smtp.your-email.com
    EMAIL_PORT=587
    EMAIL_USE_TLS=True
    EMAIL_HOST_USER=your_email@example.com
    EMAIL_HOST_PASSWORD=your_email_password
    DEFAULT_FROM_EMAIL=noreply@example.com
    ```
    *Совет: Чтобы сгенерировать `SECRET_KEY`, выполните `python -c 'from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())'`.*

3.  **Запустите Docker Compose сервисы:**
    ```bash
    docker-compose up -d --build
    ```
    Эта команда:
    * Соберет Docker-образ для вашего приложения (`web`) на основе `Dockerfile` и `requirements.txt`.
    * Запустит контейнеры для вашего Django-приложения (`web`) и базы данных (`db`) в фоновом режиме.
    * Выполнит `python manage.py collectstatic --noinput` и `python manage.py migrate` внутри контейнера `web` при первом запуске или при изменении команды в `docker-compose.yml`.

4.  **Создайте суперпользователя (для доступа к админке):**
    ```bash
    docker-compose exec web python manage.py createsuperuser
    ```
    Следуйте инструкциям в консоли для создания учетных данных.

5.  **Доступ к приложению:**
    После выполнения всех шагов, приложение будет доступно по адресу:
    [http://localhost:8000/](http://localhost:8000/)

    Административная панель Django доступна по адресу:
    [http://localhost:8000/admin/](http://localhost:8000/admin/)

## Тестирование

Проект включает набор тестов для обеспечения качества кода.

### Запуск тестов и генерация отчета о покрытии

1.  **Запустите тесты и соберите данные о покрытии кода:**
    ```bash
    docker-compose exec web coverage run --source=core,accounts manage.py test core accounts
    ```
    *(Примечание: `-source` теперь включает `core` и `accounts`, а также тесты запускаются для обоих приложений)*

2.  **Сгенерируйте сводный отчет о покрытии в консоли:**
    ```bash
    docker-compose exec web coverage report -m
    ```

3.  **Сгенерируйте интерактивный HTML-отчет о покрытии (рекомендуется):**
    ```bash
    docker-compose exec web coverage html
    ```
    После выполнения этой команды в корневой директории вашего проекта появится папка `htmlcov/`. Откройте файл `htmlcov/index.html` в вашем веб-браузере, чтобы просмотреть подробный отчет с подсветкой строк кода, показывающий, какие части кода покрыты тестами (зеленые) и какие нет (красные).

## Разработка

Для локальной разработки вы можете использовать:
* `docker-compose up` для запуска сервисов.
* `docker-compose exec web bash` для входа в консоль контейнера.
* Автоматическая перезагрузка сервера Django (`runserver`) при изменениях кода, благодаря монтированию тома `- .:/app`.
